# Button

A `<button>` with four variants and two sizes. `ButtonA` renders the same look as an `<a>`.

```jsx
import { Button, ButtonA } from "@sys42/ui";
```

```jsx live
<div className={classButtonGroup}>
  <Button onClick={() => alert("Clicked")}>Default</Button>
  <Button variant="accent">Accent</Button>
  <Button variant="highlight">Highlight</Button>
  <Button variant="danger">Danger</Button>
</div>
```

## Variants and sizes

The `accent` variant has the most contrast, `highlight` is the most vibrant, and `danger` is for errors and destructive actions. `size="lg"` scales the padding by 1.5.

```jsx live
<Stack>
  <div className={classButtonGroup}>
    <Button size="lg">Default</Button>
    <Button size="lg" disabled>Default</Button>
    <Button>Default</Button>
    <Button disabled>Default</Button>
  </div>
  <div className={classButtonGroup}>
    <Button variant="accent" size="lg">Accent</Button>
    <Button variant="accent" size="lg" disabled>Accent</Button>
    <Button variant="accent">Accent</Button>
    <Button variant="accent" disabled>Accent</Button>
  </div>
  <div className={classButtonGroup}>
    <Button variant="highlight" size="lg">Highlight</Button>
    <Button variant="highlight" size="lg" disabled>Highlight</Button>
    <Button variant="highlight">Highlight</Button>
    <Button variant="highlight" disabled>Highlight</Button>
  </div>
  <div className={classButtonGroup}>
    <Button variant="danger" size="lg">Danger</Button>
    <Button variant="danger" size="lg" disabled>Danger</Button>
    <Button variant="danger">Danger</Button>
    <Button variant="danger" disabled>Danger</Button>
  </div>
</Stack>
```

## ButtonA

`ButtonA` is a link that looks like a button. It accepts the props of `<a>` plus `variant` and `size`.

```jsx live
<div className={classButtonGroup}>
  <ButtonA href="https://github.com/receter/sys42" title="Go to GitHub">
    Link
  </ButtonA>
  <ButtonA href="https://github.com/receter/sys42" variant="accent">
    Accent link
  </ButtonA>
</div>
```

## With an icon

Use `classInlineIcon` on an inline SVG to center it in the line and cap its height at the line height.

```jsx live
<Button variant="accent">
  <svg className={classInlineIcon} viewBox="0 0 24 24" fill="currentColor" aria-hidden="true">
    <path d="M12 2 15 9h7l-5.5 4.5L18.5 21 12 16.5 5.5 21l2-7.5L2 9h7z" />
  </svg>
  &nbsp;Star
</Button>
```

## Groups

`classButtonGroup` lays buttons out in a row with a gap; `classButtonGroupReverse` reverses the order, for dialogs that put the primary action on the right. See [Helper classes](./helper-classes.mdx).

## Props

`Button` accepts all props of `<button>`, `ButtonA` all props of `<a>`, plus:

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `"accent" \| "highlight" \| "danger"` | – | The color variant. Without it, the default variant. |
| `size` | `"lg"` | – | The large size. |

## Hooks and tokens

Hooks: `useButton`, `useBaseButton`. Types: `ButtonProps`, `BaseButtonProps`.

Button is the [Button family](../tokens/families.md#button) together with SplitButton, MenuButton and the OverflowMenu trigger: it reads the `--button-*` tokens.
