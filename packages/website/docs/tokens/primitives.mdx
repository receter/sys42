# Primitive tokens

The native primitives in `primitive-tokens.css` are raw scales: `--color-{palette}-{tone}`, `--space-*`, `--size-*`, `--radius-*`, `--borderWidth-*`, `--fontFamily-*`, `--fontSize-*`, `--fontWeight-*`, `--lineHeight-*`, `--shadow-*`, `--duration-*` and `--easing-*`. They have no `s42-` prefix.

Primitives are only available if your project loads them. The semantic tokens of the native theme map to these primitives, but [your own primitives](./setup.md#your-own-primitives) can replace them entirely. Component CSS never references a primitive.

The values below are read from the stylesheet loaded by this site, so they are those of the installed `@sys42/ui`.

## Color

The color palettes are Material 3 tonal palettes named by role: `primary`, `secondary`, `tertiary`, `danger`, `warning`, `success` and `neutral`. Each has the tones 0 (black), 5, 10, 15, 20, 25, 30, 35, 40, 50, 60, 70, 80, 90, 95, 98, 99 and 100 (white). Read the [color system](../colors/color-system.mdx) for how they are generated and used.
